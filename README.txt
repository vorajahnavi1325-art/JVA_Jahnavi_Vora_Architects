JVA INTERACTIVE ARCHITECTURE WEBSITE
===================================

Open index.html in a browser.

Included:
- JVA architectural monogram drawn in SVG (no decorative dot)
- Loader runs on EVERY page refresh
- Construction-line loader animation
- Sticky navigation + animated full-screen navigation
- Hero composition inspired by the supplied moodboards
- Scroll parallax on headings, graphics and project cards
- Floating elements
- Interactive work filters
- Hover project reveals
- Project detail modal with keyboard and previous/next navigation
- About, Experience and Contact sections
- Responsive mobile layout
- Reduced-motion support
- Supplied moodboards kept locally in assets/

IMPORTANT:
The supplied moodboards are composite reference boards, so their photographs are used as local visual references/crops via CSS positioning. Replace them with original project photography or licensed images when available for a production site.
